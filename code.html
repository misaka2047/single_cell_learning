代码与数据

网站里的每个数字都来自这些脚本的真实运行。建议先读章节，再打开对应脚本；不要直接跑完所有代码而不看中间输出。

下载代码包（不含原始数据） 完整报告
**数据不在压缩包里。** 原始 GEO 文件约 60 MB，需按 [数据说明](code/DATA_README.md) 的 URL 下载；压缩包只含脚本、说明和报告。

脚本地图

文件作用
00_prepare_data.py把 GEO CSV/RPKM 读成 AnnData，补 metadata，映射基因 ID
01_baron_cluster.pyGSE84133：QC、归一化、HVG、PCA、UMAP、Leiden
02_baron_annotate.pyGSE84133：marker 注释、ARI、细胞组成
03_gse81608_cluster.pyGSE81608：QC、log2、聚类
04_gse81608_de.pyGSE81608：注释、pseudobulk DE、阳性/阴性对照
05_report_figures.py生成汇总指标和三种 DE 方法对照图
06_session_info.py记录软件版本
07_build_html.py把 REPORT.md 转成独立的完整 HTML 报告
download_ranges.py多线程 HTTP Range 下载 gzip
run_all.ps1Windows 一键按顺序运行

运行顺序

python -m pip install -r requirements.txt
$env:NUMBA_DISABLE_INTEL_SVML = "1"   # Windows 兼容性 workaround

python code/00_prepare_data.py
python code/01_baron_cluster.py
python code/02_baron_annotate.py
python code/03_gse81608_cluster.py
python code/04_gse81608_de.py
python code/05_report_figures.py
python code/06_session_info.py

你需要准备什么

  • Python 3.11–3.13；按 requirements.txt 安装依赖。
  • 至少 4 GB 内存；本教程的 h5ad 中间文件合计约 1.2 GB。
  • 能访问 NCBI FTP；下载慢时用 code/download_ranges.py。
**不要跳过 metadata 核对。** 分组、供者、细胞数对不上时，后面的所有图和统计都会错；先读 `GSE*_series_matrix.txt.gz` 的 `!Sample_characteristics_ch1`。
